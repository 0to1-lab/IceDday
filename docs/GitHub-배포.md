# GitHub로 배포하기

명령어 없이 **웹사이트에서 클릭만으로** 할 수 있어요. 이 프로젝트에는 자동 빌드 설정(`.github/workflows/release.yml`)이 들어 있어서, **GitHub가 맥에서 앱을 대신 빌드해 릴리스에 zip을 붙여 줘요.** 내 맥에서 `build.sh`를 돌릴 필요가 없어요.

받는 사람은 저장소 첫 화면의 **⬇️ 최신 버전 다운로드**를 누르면 가장 최근 zip을 받아요.

---

## 1. 처음 한 번: 저장소 만들고 코드 올리기

1. [github.com](https://github.com)에 로그인 (계정이 없으면 가입)
2. 오른쪽 위 **+** → **New repository**
3. 입력
   - Repository name: `IceDday`
   - **Public** 선택 (누구나 다운로드할 수 있게)
   - 나머지는 그대로 두고 **Create repository**
4. 새로 생긴 빈 저장소 화면에서 **uploading an existing file** 클릭
5. Finder에서 `IceDday` 폴더를 열고 `⌘ + Shift + .`을 눌러 숨김 파일을 보이게 한 뒤, 안에 있는 것을 **전부 선택해서** 브라우저로 끌어다 놓기
   - `.github` 폴더(자동 빌드 설정)와 `.gitignore`도 꼭 같이 올려요
   - `node_modules`와 `build` 폴더는 **빼고** 올려요
6. 아래 **Commit changes** 클릭

올리고 나면 저장소 위쪽 **Actions** 탭에서 빌드가 자동으로 돌아가요. 2~4분 뒤 초록색 ✓가 뜨면 성공이에요. 빨간 ✗가 뜨면 눌러서 나온 오류 화면을 캡처해 주세요.

## 2. 릴리스 만들기 (배포)

1. 저장소 화면 오른쪽의 **Releases** → **Create a new release**
   (안 보이면 주소창에서 저장소 주소 뒤에 `/releases/new`를 붙여 이동)
2. **Choose a tag** 칸에 `v1.0` 입력 → **Create new tag** 클릭
3. 제목·설명은 비워 둬도 돼요 (자동으로 채워짐)
4. **Publish release**
5. 2~4분 기다리면 릴리스 아래에 `Ice-D-day-1.0.zip`이 자동으로 붙어요

## 3. 새 버전 올리기

1. 바뀐 파일을 1번의 4~6처럼 다시 올리기 (같은 이름 파일은 덮어써져요)
2. 2번처럼 릴리스를 만들되 태그를 `v1.1`, `v1.2`처럼 올려서 만들기
   → zip 이름도 `Ice-D-day-1.1.zip`처럼 자동으로 바뀌어요

## 받는 사람이 하는 일

1. 저장소 첫 화면에서 **⬇️ 최신 버전 다운로드** → `Ice-D-day-x.x.zip` 클릭
2. zip을 더블클릭해서 풀고, `Ice D-day` 앱을 **응용 프로그램** 폴더로 옮기기
3. 처음 열 때 "확인되지 않은 개발자" 경고가 뜨면
   **완료** → **시스템 설정 → 개인정보 보호 및 보안** 맨 아래 **그래도 열기** → 다시 열기
4. 처음 실행하면 뜨는 설정창에서 D-day와 사진 정하기 (나중엔 메뉴바 ❄️에서)

필요한 것: macOS 14(Sonoma) 이상.

## 알아두면 좋은 것

- **경고 없이 열리게 하려면** 애플 개발자 프로그램(연 $99) 가입 후 앱 서명·공증이 필요해요. 비상업 배포라면 위 3번 안내로 충분해요.
- **라이선스**: 다른 사람이 코드를 어떻게 써도 되는지 정해 두고 싶으면 저장소에서 **Add file → Create new file** → 파일 이름에 `LICENSE` 입력 → 오른쪽의 **Choose a license template**에서 고를 수 있어요.
- 다른 사람 사진이나 캐릭터 그림을 예시로 올리지 않도록 주의하세요. 저장소는 공개라서 누구나 볼 수 있어요.
