# ❄️ Ice D-day

### [⬇️ 최신 버전 다운로드](../../releases/latest)

받은 zip을 풀고 `Ice D-day` 앱을 **응용 프로그램** 폴더로 옮기면 끝이에요. 처음 열 때 경고가 뜨면 아래 [친구에게 나눠 주기](#3-친구에게-나눠-주기)를 참고하세요.

바탕화면에 떠 있는 3D D-day 위젯이에요. 내가 고른 사진이 들어가고, D-day가 다가올수록 모습이 바뀌어요.

| 테마 | 진행되는 모습 | 클릭하면 | D-day |
|---|---|---|---|
| ❄️ 얼음 (각얼음·얼음 공·수정 모양) | 성에가 걷히며 사진이 또렷해지고, 위에서부터 녹아내림 | 한 바퀴 휙 돌기 | 사진이 풀려나 통통 |
| 🍞 오븐 (레트로 오븐, 색 5가지) | 사진 누끼 모양 그대로의 캐릭터빵이 부풀고 노릇하게 구워짐. 빵 윗면엔 사진이 구운 자국으로 찍히고 | 문이 열려 안을 보여줌 | 띵! 빵이 나오고 펑! 오븐이 사라지며 하얀 접시에 담긴 빵만 남음 |
| 🥚 알 (하얀 달걀·갈색 달걀·공룡알은 바닥에 알만, 판타지 알은 금색 받침대) | 무드등처럼 안에서 점점 밝게 빛남. 금이 늘며 껍질 부스러기가 떨어지고 갈수록 자주 꿈틀 | 흔들흔들 | 윗껍질이 날아가고 사진이 나옴 |

- macOS 14(Sonoma) 이상, Apple 실리콘·인텔 맥 모두
- **윈도우 10·11(64비트)도 지원** → 아래 [윈도우 버전](#윈도우-버전) 참고
- 테두리 없는 투명 창이라 바탕화면 위에 물체만 보여요 (물체 없는 곳은 클릭이 바탕화면으로 통과)
- 사진 배경은 맥에 내장된 기능으로 자동 제거 (인터넷 전송 없음)

---

## 1. 처음 한 번: 빌드하기

터미널을 열고 이 폴더로 이동한 뒤:

```bash
xcode-select --install     # Swift 컴파일러 설치 (처음 한 번, 이미 있으면 건너뜀)
bash build.sh
open "build/Ice D-day.app"
```

`build/` 폴더에 앱(`Ice D-day.app`)과 배포용 zip이 생겨요. 앱은 **응용 프로그램** 폴더로 옮겨 두면 좋아요 (로그인 시 자동 실행이 그래야 동작해요).

## 2. 쓰는 법

| 하고 싶은 것 | 방법 |
|---|---|
| D-day·제목·테마·사진 정하기 | 메뉴바 **❄️** → **D-day 설정…** (위젯을 오른쪽 클릭해도 같은 메뉴) |
| 테마 반응 보기 | 위젯을 **클릭** (얼음 돌기 / 오븐 문 열기 / 알 흔들기) |
| 돌려 보기 | 위젯을 좌우로 **드래그** (놓으면 조금 더 돌다 멈춤) |
| 위치 옮기기 | 위젯을 **길게 누르면**(살짝 커지며 들림) 그대로 끌어서 이동. **⌘(command)** 누른 채 드래그해도 돼요 |
| 크기 바꾸기 | 위젯 위에서 **⌥(option) + 스크롤**, 또는 트랙패드 **두 손가락 벌리기/오므리기**. 메뉴 → 크기의 슬라이더나 설정창에서 50~135% 사이로 5%씩 조절 |
| 테마 바꾸기 | 메뉴 → 테마, 또는 설정창 |
| 오븐 색 바꾸기 | 메뉴 → 오븐 색, 또는 설정창 (빨강·민트·크림·하늘색·검정) |
| 사진 넣기 | 메뉴 → **사진 고르기…** (위젯마다 따로) |
| 메뉴 | 메뉴바 ❄️ 아이콘, 또는 위젯을 **오른쪽 클릭** |
| 처음부터 끝까지 한번에 보기 | 메뉴 → **진행 과정 미리보기** (마지막에 D-day 장면까지: 얼음이 풀리고, 빵이 접시에 담겨 나오고, 알이 깨짐) |
| D-day 여러 개 | 메뉴 → **＋ 위젯 추가**. 위젯마다 D-day·제목·사진·테마·크기·위치가 따로예요. 없앨 땐 그 위젯을 오른쪽 클릭 → **이 위젯 닫기**. 위젯이 여러 개면 메뉴바 ❄️ 메뉴에 위젯별로 나뉘어 보여요 |
| 켤 때마다 자동으로 띄우기 | 메뉴 → **로그인 시 자동 실행** |

날짜를 새로 정하면 (그 위젯만) 그 순간 처음 상태(꽁꽁 언 얼음, 반죽, 멀쩡한 알)로 돌아가고, 그날부터 D-day까지 천천히 진행돼요. 제목이나 테마만 바꾸면 진행 정도는 그대로예요.

## 3. 친구에게 나눠 주기

GitHub 릴리스로 올리는 방법은 [docs/GitHub-배포.md](docs/GitHub-배포.md)에 있어요. 릴리스를 만들면 GitHub가 앱을 자동으로 빌드해서 zip을 붙여 줘요. 파일로 직접 줄 때는 `build/Ice-D-day-1.1.zip`을 보내면 돼요. 받는 사람은 zip을 풀고 앱을 **응용 프로그램** 폴더로 옮기면 끝.

> 애플 개발자 등록(유료)을 하지 않은 앱이라, 처음 열 때 "확인되지 않은 개발자" 경고가 떠요.
> 1. 앱을 한 번 열어 보고 경고가 뜨면 **완료**를 누름
> 2. **시스템 설정 → 개인정보 보호 및 보안** 맨 아래의 **그래도 열기** 클릭
> 3. 다시 열기 → 이후로는 그냥 열려요

## 4. 모양 고치기 (바이브 코딩용)

3D 장면은 `src/` 폴더에 있어요. 테마마다 파일이 하나씩이라 고치고 싶은 테마 파일만 열면 돼요.

- `src/themes/ice.js` — `PHOTO_MAX` 사진 크기, `MARGIN` 얼음 두께, `THAW_END`·`MELT_START` 녹는 시점
- `src/themes/oven.js` — 빵 색(`bake`), 오븐 모양(`buildRetro`), 접시(`makePlate`), 오븐 색(`OVEN_COLORS`)
- `src/themes/egg.js` — 알 크기(`H`, `R`), 껍질 무늬(`basePattern`), 금 모양(`makeCrackNet`)
- `src/main.js` — 공통 (카메라, 회전, 색종이, 라벨)

새 테마를 추가하려면 `src/themes/`에 파일을 하나 만들고 `src/main.js`의 `THEMES`, `Sources/main.swift`의 `themes`, `win/main.js`의 `THEMES` 목록에 한 줄씩 넣으면 돼요.

고친 뒤:

```bash
npm install          # 처음 한 번 (Node.js 필요)
npm run build:web    # src/ → web/ice.bundle.js
```

**브라우저로 바로 확인**: `web/index.html`을 크롬이나 사파리로 열면 위쪽에 진행도 슬라이더와 테마 선택이 생겨서, 앱을 다시 빌드하지 않고도 모습을 볼 수 있어요. 클릭·드래그도 앱처럼 돼요. `npm run watch:web`을 켜 두면 저장할 때마다 자동으로 다시 만들어져요. 다 고쳤으면 `bash build.sh`로 앱에 반영.

## 윈도우 버전

`win/` 폴더에 있어요. 3D 장면(`src/`)은 맥과 똑같이 쓰고, 껍데기만 Electron으로 만들었어요.

**받는 사람**
1. `Ice-D-day-Windows-x.x.zip`을 오른쪽 클릭 → **압축 풀기** (zip 안에서 바로 실행하면 설정이 저장되지 않아요)
2. 풀린 `Ice D-day` 폴더를 원하는 곳(예: 문서)에 두고 `Ice D-day.exe` 실행
3. 파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** (서명하지 않은 앱이라 처음 한 번만 떠요)
4. 처음 실행하면 뜨는 설정창에서 D-day와 사진 정하기

**맥과 다른 점**

| | 맥 | 윈도우 |
|---|---|---|
| 메뉴 | 메뉴바 ❄️ | 작업 표시줄 오른쪽 아래 트레이 아이콘 (안 보이면 `^` 눌러서) · 위젯 오른쪽 클릭 |
| 위치 옮기기 | 길게 눌러 끌기 / ⌘+끌기 | 길게 눌러 끌기 / **Ctrl**+끌기 |
| 크기 | ⌥+스크롤 / 핀치 | **Alt+휠** 또는 **Ctrl+휠** / 터치패드 핀치 |
| 누끼 | 맥 내장 기능 (무엇이든) | 배경이 단색이면 그 색을 지우고, 아니면 사람만 찾아서 남김. 캐릭터·물건 사진은 배경이 단순할수록 깔끔해요. 이미 배경이 투명한 PNG는 그대로 써요 |
| 창 겹침 | 바탕화면 바로 위 층 | 맥과 같아요: 다른 창이 위젯을 덮고, Win+D(바탕화면 보기)를 누르면 위젯이 보여요. 메뉴의 **항상 위에 표시**를 켜면 늘 맨 위 |
| 종료 | 메뉴바 ❄️ → 종료 | 위젯 오른쪽 클릭 → **종료**, 또는 작업 표시줄 오른쪽 아래 트레이 아이콘(안 보이면 `^`) → 종료 |
| 화질 | — | 느린 컴퓨터면 자동으로 **가볍게** 바뀜 (메뉴 → 화질) |

저장 위치: 설정과 누끼 결과는 `%APPDATA%\Ice D-day\`.

**직접 빌드** (맥·리눅스·윈도우 어디서나, Node.js 필요)

```bash
npm install                 # 처음 한 번 (이 폴더에서)
cd win
npm install                 # 처음 한 번
npm start                   # 내 컴퓨터에서 바로 실행해 보기
npm run dist                # win/dist/Ice-D-day-Windows-1.0.0.zip 만들기
```

## 파일 구성

```
Sources/main.swift   맥 앱 껍데기 (투명 창, 마우스, 설정창, 자동 누끼, 메뉴바)
win/                 윈도우 앱 껍데기 (Electron: main.js, 설정창, 누끼 cutout.js, 마우스 input.js)
src/main.js          3D 장면 공통 부분 (Three.js)
src/themes/          테마별 장면: ice.js, oven.js, egg.js
src/util.js          테마들이 같이 쓰는 도구
web/                 앱 안에 들어가는 화면 (index.html + 빌드된 ice.bundle.js)
assets/icon.png      앱 아이콘
build.sh             앱 + 배포용 zip 만들기
docs/                배포 안내
```

저장 위치: 설정은 앱 기본 설정, 누끼 결과는 `~/Library/Application Support/IceDday/cutout-(위젯 id).png`.
